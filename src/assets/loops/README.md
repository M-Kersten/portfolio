# Film loops

A short, silent loop of each project's film: the first thing a project's
label shows, playing on its own the moment the label opens. Pick the
strongest 6–10 seconds. Name the file after the project's slug (its `slug` in
`src/content/cases.json`):

    alliander-hololens.mp4
    arcam.webm

`.mp4` (H.264) or `.webm`, **no audio track**, around 720 px wide, and a few
hundred KB at most. A project without a loop shows its poster drifting slowly
instead; the full film (with sound) still plays when the label is pressed.
